# Writing folder: what each thing is

## `latex/`
The report project: `main.tex`, figures, fonts, the bundled compiler and the VS Code setup.
**This is the master copy. Edit here.** Its `README.md` is the guide for whoever compiles it.

## Sending the report to someone
Right-click `latex/` in Finder → **Compress "latex"**, and send the resulting `latex.zip`.
It contains everything they need, including the compiler. They follow `latex/README.md`.

## `reference/`
Course and background material. **Not used to build the report**, and kept out of this repo (local copy only).
